Agents shine when the workflow is repetitive, toolable, and measurable. They fail when autonomy is unbounded.

## Constrain the tool surface

Give agents a small set of well-tested tools with clear side effects. Prefer human approval for irreversible actions.

## Memory with purpose

Short-term conversation state and long-term retrieval should be explicit. Blind memory growth creates cost and confusion.

## Measure ROI

Track hours saved, error rates, and escalation frequency. If an agent cannot beat a scripted automation on reliability, it is not ready for production ownership.
